nab'd — logo assets
===================

The name
  Written nab'd wherever a person reads it. Written nabd where an
  apostrophe is impossible: the domain, the package, the binary,
  file paths, social handles. File names here use the plain form.

Palette
  Nab'd Purple  #6c3baa    logo field, primary actions
  Purple Light  #9B6BD8    dark UI only (Nabd Purple is 2.7:1 on near-black)
  Purple Deep   #4E2A7D    pressed / hover
  Cream         #E8E4DC    the logo on purple
  Ink           #17161A    the logo on light
  Shell         #0A0A0C    app background

Files
  nabd-lockup-purple-field.svg   PRIMARY. Mark + wordmark on the purple field.
  nabd-lockup-cream.svg          Lockup, transparent, for placing on your own purple.
  nabd-lockup-ink.svg            Lockup for light grounds.
  nabd-stacked-*.svg             Use only below the 120px minimum width.
  nabd-mark-*.svg                Mark alone. Min 20px.
  nabd-wordmark-*.svg            Wordmark alone, for running text and footers.
  nabd-app-tile-512.svg          App icon / favicon. Corner radius 22.5%, ring 58%.
  nabd-tray-template.svg         Menu bar / tray. Uses currentColor - tint it per platform.

Rules that matter
  - The gap sits at 1 o'clock. Never rotate the mark.
  - Never close the gap, recolour the ring, or add shadows or gradients.
  - The wordmark is drawn artwork, not a typeface. Never re-set it in a font.
  - The apostrophe is part of the wordmark. Never drop it, never swap it
    for a straight quote glyph in the artwork.
  - Minimum sizes: lockup 120px / 32mm, app tile 16px, mark alone 20px.
  - Clear space on all four sides = half the mark's height.

Typography
  Outfit          interface and marketing
  JetBrains Mono  hotkeys, paths, durations, version strings
